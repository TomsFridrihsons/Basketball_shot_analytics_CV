# Unnecessary Files List for HooperAI Project Cleanup

This document lists files and directories that can be safely removed to clean up the project.

## 🗑️ High Priority - Safe to Delete

### 1. **Python Virtual Environment** (Can be regenerated)
- `.venv1/` - Entire virtual environment directory
  - **Reason**: Virtual environments should not be committed to repositories. Can be recreated with `python -m venv .venv1` and `pip install -r requirements.txt`
  - **Size**: Very large (contains all installed packages)

### 2. **Training Output Cache Files** (Regenerated automatically)
- `Hooper-2/train/labels.cache`
- `Hooper-2/valid/labels.cache`
- `HooperAnalytic-1/train/labels.cache`
- `HooperAnalytic-1/valid/labels.cache`
  - **Reason**: Cache files generated during YOLO training. Automatically regenerated when needed.

### 3. **Roboflow Metadata Files** (Not essential for project)
- `Hooper-2/README.dataset.txt`
- `Hooper-2/README.roboflow.txt`
- `HooperAnalytic-1/README.dataset.txt`
- `HooperAnalytic-1/README.roboflow.txt`
  - **Reason**: Just metadata from Roboflow dataset downloads. Not needed for actual work.

### 4. **All Prediction Output Directories** (Temporary outputs)
- `runs/detect/predict/` through `runs/detect/predict31/` (32 directories)
  - Contains: `.txt` label files (thousands), `.avi` output videos
  - **Reason**: These are temporary prediction outputs. Can be regenerated by running predictions again.
  - **Note**: `predict31` contains 471 .txt files + 1 .avi file

### 5. **All Tracking Output Directories** (Temporary outputs)

## 📊 Summary Statistics

- **Total prediction directories**: 32 (predict, predict2-predict31)
- **Total tracking directories**: 15 (track, track2-track14)
- **Total pose prediction directories**: 6
- **Estimated files to delete**: 10,000+ temporary output files
- **Virtual environment**: ~GBs of space

## 🎯 Recommended Cleanup Strategy

1. **Delete immediately**:
   - `.venv1/` directory
   - All `labels.cache` files
   - All Roboflow README files
   - All prediction/tracking/pose output directories

2. **Keep but organize**:
   - Trained model weights (`best.pt` files) - consider moving to a `models/` directory
   - Training configs (`args.yaml`) - useful for reference

3. **Review before deleting**:
   - `dataset/sportus/` images
   - Training visualization files (if you want to keep historical training records)

## 💡 Recommendations

1. **Create a `.gitignore`** file to prevent committing:
   - `runs/` directory
   - `.venv*/` directories
   - `*.cache` files
   - `__pycache__/` directories

2. **Consider keeping only**:
   - Latest/best trained models
   - Source code (if any exists)
   - Dataset directories (`Hooper-2/`, `HooperAnalytic-1/`)

3. **Archive old runs** if needed:
   - Compress old training runs if you want to keep them for reference
   - Move to external storage
