# Notebooks Directory

This directory contains Jupyter notebooks for data exploration, analysis, and experimentation.

## Structure

```
notebooks/
├── exploration/          # Data exploration notebooks
├── analysis/            # Analysis notebooks
├── experiments/         # Experimental notebooks
└── README.md           # This file
```

## Usage

- **Exploration**: Initial data exploration and visualization
- **Analysis**: Model performance analysis, metrics comparison
- **Experiments**: Quick experiments and prototyping

## Best Practices

- Keep notebooks organized by purpose
- Clear outputs before committing
- Document findings in markdown cells
- Export important results to `../evaluations/`

## Note

Notebooks are excluded from Git by default (see `.gitignore`). 
To track notebooks, add them explicitly or remove `*.ipynb` from `.gitignore`.
