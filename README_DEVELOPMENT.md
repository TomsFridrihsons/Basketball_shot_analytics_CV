## Workflow

1. **Make changes** in this branch
2. **Test locally** as much as possible
3. **Commit** your changes
4. **Push** to `development` branch
5. **When ready**, merge to `testing` branch for validation

## Merging to Testing

```bash
git checkout testing
git merge development
git push origin testing
```
