# Scripts Directory

This directory contains utility scripts and tools for the project.

## Available Scripts

### Training Scripts
- **`train_colab.py`** - Training script for Google Colab (available in `colab-training` branch)
  - See [../docs/colab_setup.md](../docs/colab_setup.md) for usage instructions

## Usage

Scripts in this directory can be run directly or imported as modules depending on their purpose.

## Adding New Scripts

When adding new scripts:
1. Place them in this `scripts/` directory
2. Add a brief description in this README
3. Include usage instructions in the script's docstring
4. Update relevant documentation in `docs/` folder

---

**Note**: Training scripts are primarily in the `colab-training` branch.
